# 多摄预览工具

横屏调试应用，用于在设备上同时预览多路摄像头（CVBS / HDMI / 环视等），方便现场对画面、分辨率和采集参数。

面向带 Camera2 的 Android 板卡（如 alps C50）。应用会枚举系统摄像头，每路一个可拖动、缩放的预览窗口。

## 运行

1. 用 Android Studio **Run** 安装到设备（不要用 Debug 做日常预览）。
2. 授予摄像头权限。
3. 应用锁定横屏。

也可直接安装仓库里的 release 包：[`apk/MultiCameraPreview_v1.0_release.apk`](apk/MultiCameraPreview_v1.0_release.apk)。

手动打 release 包：Android Studio 菜单 **Build → Generate Signed App Bundle or APK → APK**，选 release；或命令行在工程根目录执行 `gradlew.bat :app:assembleRelease`。成品在 `app/build/outputs/apk/release/MultiCameraPreview_v1.0_release.apk`。当前工程没有独立发布证书，release 使用 debug 签名，方便调试板安装。

## 窗口操作

- 点击画面：显示 / 隐藏标题栏（默认隐藏）。
- 拖动标题栏或画面：移动窗口；靠近屏幕边缘或其他窗口会吸附。
- 角上手柄：拉伸窗口，同样支持吸附对齐。
- **等比 / 自由 / 1:1**：画面如何铺满窗口。
- 旋转按钮：只转画面，外框大小不变；标题栏贴到与画面方向一致的那条边上。
- **[ ]**：全屏；再点画面或按返回键退出。
- 点击标题栏分辨率 / 帧率：切换采集参数。

## 设置栏

右上角 **设置** 打开侧栏。**关闭** 收起；图钉固定后，点外面不会收起。

侧栏可做：

- 默认使用 OpenGL 打开
- 各路摄像头开关、白底
- 手动选择 IC（无 / TP9951 / TP2815 / TP2815_SUB / LT6911C）
- CVBS（TP9951）进入 **参数**（去隔行、NTSC/PAL 预设、算法）
- HDMI（LT6911C）查看输入分辨率、信号、音频
- **还原默认布局**：只恢复位置、大小、旋转、等比和叠放顺序，不改 IC 和参数

返回键顺序：退出全屏 → 退出参数/子页 → 关闭侧栏 → 退出应用。

## IC 类型

| 选项 | 用途 |
|------|------|
| 无 | 当普通摄像头预览 |
| TP9951 | CVBS，可开去隔行参数 |
| TP2815 / TP2815_SUB | 环视采集，画面由底层输出，应用不再拼 2×2 |
| LT6911C | HDMI 采集 |

未识别时可在侧栏手动指定。切换 IC 后该路分辨率会按新类型重新选择。

## 状态记忆

杀进程再打开会恢复：

- 窗口位置、大小、旋转、等比 / 1:1
- 窗口前后叠放顺序
- 摄像头开关、IC、分辨率、帧率
- 去隔行参数、白底
- 设置栏图钉、默认 OpenGL

**还原默认布局** 不会清掉 IC 和参数。按 Home 再回来只是暂停预览，不算重启；测记忆请用 Android Studio **Stop** 后再 **Run**，或从最近任务划掉再打开。
